# Network Scanning & Security Report

Ran a network scan using Nmap on Kali Linux and wrote the results up as a professional security report.

---

## What I Did

This project has two parts: networking fundamentals study and a hands-on scanning lab.

For the lab, I used Nmap on Kali Linux to scan a network: identified live hosts, found open ports, and detected what services were running on each one. I then wrote everything up as a security report.

---

## Files

**network-basics.md**
Study notes on core networking concepts — OSI model, TCP/IP, IP addressing, subnetting, DNS, DHCP, and common protocols with their port numbers.

**network-scan-and-report.md**
The full lab — scan methodology, what Nmap found, and a security analysis of the results including which open ports are risks and why.
